# 방 탈출 예약 관리 

## 기능 요구사항

### 1단계 - 홈 화면
- [x] '/' 요청 시 홈 화면('home.html')을 응답한다.

### 2단계 - 예약 조회
- [x] '/reservation' 요청 시 예약 관리 페이지('reservation.html')를 응답한다.
- [x] '/reservations' 요청 시 예약 목록을 JSON으로 응답한다.

### 3단계 - 예약 추가/삭제

- [x] '/reservations' POST 요청 시 예약을 추가한다.
- [x] 예약 추가 시 생성된 예약의 ID를 응답한다.
- [x] 예약 추가 성공 시 201 Created를 응답한다.
- [x] 예약 삭제 시 해당 예약을 삭제한다.
- [x] 예약 삭제 성공 시 204 No Content를 응답한다.

### 4단계 - 예외 처리

- [x] 예약 추가 시 필요한 값이 비어있으면 400 Bad Request를 응답한다.
- [x] 존재하지 않는 예약을 삭제하려 하면 404 Not Found를 응답한다.
- [x] `@ControllerAdvice`를 사용해 전역 예외 처리를 구현한다.
- [x] `@ExceptionHandler`를 사용해 예약 관련 예외를 적절한 Status Code로 변환한다.
