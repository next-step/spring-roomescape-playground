# 무엇을 얻었나요?

코드를 작성할 때 깊은 고민과 내가 미션을 해결하기 위해서 자료를 찾아보고 다른 방법과 비교해보면서
문제를 해결하려는 자세, 깊이 고민한 내용으로 나만의 철학을 만들고 이를 바탕으로 개발의 효율성 상승.

나의 상황에 맞는 본인만의 학습 방법 -> 현재 하고 있는 일이 많지만 이 상황 속에서 내가 얻어갈 수 있는 최선의 방법을 
계속해서 고민하고 현재 나의 고민들을 공유했다. 나보다 먼저 이런 고민들을 했던 선배들은 어떻게 해결해나갔는지 질문하며 
생각의 확장을 할 수 있었다.

커뮤니티, 스터디를 참여하게된 계기는 우테코 6기를 지원하게되면서 알게된 인연을 통해서 해볼 의향이 있는지 질문을 받았다.
부트캠프를 시작해서 시간이 될지 잘 모르겠지만, 다른 사람들과 함께 미션을 진행하면서 소통하고 우테코 5기를 했던 사람들에게
리뷰를 받을 수 있어서 참여하게 되었다.
