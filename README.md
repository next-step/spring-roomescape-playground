# Spring MVC [1~2단계]

## 기능 목록

### 홈 화면

- [x] 사용자가 `/`로 요청하면 어드민 메인 페이지를 볼 수 있다.

### 예약 관리 화면

- [x] 사용자가 `/reservation`으로 요청하면 예약 관리 페이지를 볼 수 있다.

### 예약 목록 조회

- [ ] 사용자가 `/reservations`로 요청하면 예약 목록을 JSON 배열로 조회할 수 있다.
- [ ] 예약 데이터가 없으면 빈 배열을 응답한다.

## 테스트 기준

### 홈 화면

- [x] `GET /` 요청 시 상태 코드 200과 HTML을 반환한다.

### 예약 관리 화면

- [x] `GET /reservation` 요청 시 상태 코드 200을 반환한다.

### 예약 목록 조회

- [ ] `GET /reservations` 요청 시 JSON 배열을 반환한다.
- [ ] 예약 목록이 비어 있다면, 빈 배열을 응답한다. 예외 상황으로 보지 않는다.
