# 방탈출 어드민 애플리케이션 미션

## 기능 목록

### 'HomeController'

- [x] `/` 요청 시 어드민 메인 페이지를 응답한다.
- [x] `/reservation` 요청 시 예약 관리 페이지를 응답한다.
- [x] `/reservations` 요청 시 예약 목록을 응답한다.

### 'Reservation'

- [x] 예약 번호를 관리한다.
- [x] 예약자 이름을 관리한다.
- [x] 예약 날짜를 관리한다.
- [x] 예약 시간을 관리한다.

### 'Gradle'

- [x] Spring Web 의존성을 추가한다.
- [x] Thymeleaf 의존성을 추가한다.


### 리뷰 반영

- [ ] 예약 조회 시 예약 데이터가 중복으로 추가되지 않도록 수정한다.
- [ ] 예약 날짜 매개변수를 date로 통일한다.
- [ ] 현재 사용하지 않는 toEntity() 메서드를 제거한다.
